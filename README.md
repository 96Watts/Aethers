# Aether Website

The official Aether download and product website.

Aether is a Windows desktop AI workspace for local Ollama models and supported OpenAI-compatible services.

## Website

After GitHub Pages is enabled, visit:

```text
https://96watts.github.io/Aethers/
```

## Deployment

This repository deploys the `site/` folder through GitHub Actions. In repository settings, set:

```text
Settings -> Pages -> Build and deployment -> Source: GitHub Actions
```

The website links to the Aether application repository and its GitHub Releases for the Windows installer.
